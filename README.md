# Booknora

A modern, responsive bookstore storefront built with Next.js, TypeScript and Tailwind CSS.

## Getting started

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Features

- Responsive bookstore landing page
- Three selectable visual themes (Editorial, Midnight, Rose)
- Search, category filtering, wishlist and cart interactions
- Demo checkout flow (frontend only)

> Checkout is a UI demo. No real payment, inventory or order persistence is configured.
